## Cannot fix in a small patch

- True cancellation of native Whisper/LLama/Vosk/ONNX inference; needs process isolation or upstream APIs.
- Full cancellation for Kokoro/Piper downloads/synthesis without library support.
- Signed/privileged updater; re-hash/ACL helps but is not complete.
- Full screen-reader parity for freeform graph/timeline; needs parallel accessible model.
- Timeline cut/paste requires host-side clip snapshot/addressability.
- Responsive shell requires a layout model, not one media query.
- Roaming→Local model migration needs compatibility/dual-path support.
- Stable PID identity for per-app capture is constrained by Windows loopback.
- Unencrypted network audio is an intentional protocol choice, not a bug to patch silently.
- Untracked binary assets must be committed or fetched with pinned hashes.
